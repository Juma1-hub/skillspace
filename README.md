# SkillSpace

A SkillSpace rebuild inspired by the public information architecture and visual style of Arcade Writers, while retaining SkillSpace branding and its own task-platform rules.

## Stack
- Next.js App Router
- Supabase
- Vercel

## Pages
- Landing page
- Login / Sign up
- Dashboard
- Tasks and task detail
- Article Writing
- Transcription
- Data Annotation
- Surveys
- Transactions
- Earnings
- Withdraw
- Profile
- Settings
- Support
- Admin

## Important
This package is a clean starter UI and integration structure. Add your Supabase environment variables in Vercel before production deployment.
